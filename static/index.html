Architecture: this page (static HTML/JS) calls GET /api/maze and GET /api/grover on a Flask backend. The backend builds a Grover oracle + diffuser in Qiskit, runs it on the Aer simulator, and returns the measurement counts as JSON — the quantum computation itself never touches the browser.
